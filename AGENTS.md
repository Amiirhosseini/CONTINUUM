# Standing rules

Rules that apply to every task in this repository, with no exceptions.

1. No em dashes anywhere in user-facing text: issue titles and bodies, pull requests, commit messages, documentation. Use commas, periods, or parentheses instead.

2. No AI attribution or fingerprints. Never state or imply that content was AI-generated, and do not reference agent or tool names in issue or pull request text. Issues should read as if filed by the project maintainer.

3. Never force-push to any branch (main or otherwise) without asking first and receiving explicit confirmation, even when using `--force-with-lease` and even when amending a commit that was just pushed. If a force-push appears necessary, stop and explain why instead of performing it.
