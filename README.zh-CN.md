<p align="center">
  <strong>CONTINUUM：面向长时间运行 AI 智能体的可验证语义恢复。</strong>
  语义检查点（而非对话转储）、拒绝重复副作用的幂等动作账本，以及哈希链防篡改事件日志，全部通过默认拒绝的 MCP 服务器暴露。框架无关，支持 Python 3.11+。
</p>
