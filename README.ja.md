<p align="center">
  <strong>CONTINUUM: 長時間実行される AI エージェントのための検証可能な意味的リカバリ。</strong>
  セマンティックチェックポイント（会話のダンプではない）、重複する副作用を拒否する冪等なアクション台帳、
  そしてハッシュチェーンによる改ざん証跡ログを、デフォルトで拒否する MCP サーバーとして公開。フレームワーク非依存、Python 3.11+。
</p>
