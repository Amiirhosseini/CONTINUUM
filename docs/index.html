Core Differentiation

Built from the ground up for agent execution fault tolerance.

01 / CHECKPOINTS

Semantic Checkpoints

Replaces massive raw chat dumps with a compact, inspectable tree of verified goals, decisions, findings, evidence, and pending tasks.

02 / VALIDATION

Environment Validation

Compares stored state against the live environment before resuming. Automatically flags modified dependencies or stale decisions.

03 / LEDGER

Idempotent Action Ledger

Tracks external side effects (API calls, DB writes). Intercepts duplicate executions on crash recovery and returns original cached results.

04 / EVENT LOG

Tamper-Evident Audit Chain

Append-only event log hash-chained with SHA-256 digests (`e1.hash → e2.prev_hash`). Provides verifiable provenance for all state components.

05 / CONTRACTS

Recovery Contracts

Generates deterministic machine-readable contracts specifying state validity, invalidated items, and next allowed recovery actions.

06 / LOCAL-FIRST

Framework-Agnostic & CPU-First

Runs locally with SQLite WAL journaling and Pydantic v2. Zero mandatory cloud services, zero vector DB requirements, zero GPU dependencies.

Developer Quickstart

Framework-agnostic Python library with simple, typed APIs.

# Python SDK Quickstart
from continuum import Continuum

# Initialize local SQLite storage
runtime = Continuum(storage="sqlite:///agent.db")

# Start a run
run = runtime.start(goal="Analyze 10,000 research documents")

# Record progress and findings
run.record_finding(claim="Strong correlation observed", confidence=0.94)
run.update_progress(completed=3421, pending=6579)

# Checkpoint semantic state
run.checkpoint()

# Record external side effects safely
run.record_action(type="github.create_issue", arguments={"title": "Bug found"})

# Resume after crash
recovered_run = runtime.resume("run_4821")
status = recovered_run.validate()

if status.safe:
    recovered_run.continue_execution()
